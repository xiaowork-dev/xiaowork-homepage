- 精确锁定依赖、npm lockfile、严格类型、零警告 ESLint、Prettier 与基础编辑器配置。
- 首页/项目/关于路由、共享布局、导航、主题、卡片、标签及静态项目数据模型。
- 默认深紫、浅色切换、偏好记忆、减少动效和基础键盘支持。
- 桌面/手机布局与菜单基础检查；真实图片和链接仍为明确占位。
