## 素材接入后的必做验证

1. 只修改 `app/data/site.ts`、`about.ts`、`projects.ts`、`project-covers.ts` 和对应本地资源；记录本人确认来源及公开边界，不在 Git 留敏感原图。
2. 使用新图片文件名；检查 16:10 裁切、960×600 预留区域、alt、现代格式和失败后备；真实素材加入后重测 LCP/体积。
3. 外链确认 HTTPS 和实际可达，核对公开页面身份；异常则隐藏。状态和技术栈须由本人确认，不能根据网站外观推断。
4. 复跑规范、类型、生成、HTTP、双主题及手机浏览器；重新提交推送，形成新的已验收 SHA。
